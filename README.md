# Uno Super War da Vida — downloads

Um jogo de **God2Korp**. Aqui ficam só as versões do jogo para quem está ajudando nos testes.

## Como jogar (Windows 10 ou 11)

1. Abra a [versão mais nova](https://github.com/llululee/Uno-Super-War-da-Vida-Downloads/releases/latest) e baixe o arquivo `...-Windows.zip`.
2. Extraia a pasta inteira (por exemplo, na Área de Trabalho) e abra `Uno Super War da Vida.exe`.
3. Se o Windows avisar, clique em **Mais informações** > **Executar assim mesmo**.

Depois da primeira vez, o jogo se atualiza sozinho: quando sair uma versão nova, o menu inicial mostra **Atualizar agora**.

## Jogar online

Uma pessoa vai em **Jogar > Criar sala online** e passa o código de 6 letras (botão **Copiar código**). Os outros entram em
**Jogar > Entrar numa sala online** com o mesmo código. Todos precisam estar com a mesma versão.
